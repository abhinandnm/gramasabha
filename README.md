# GramaSabha — Maintenance

> GramaSabha is currently undergoing scheduled maintenance.
> We will be back shortly.

---

## Status

The application is temporarily offline for updates and improvements.
Thank you for your patience.

---

## Branch Purpose

This branch is used when the application is taken offline for:

- Server upgrades or migrations
- Major feature deployments
- Bug fixes requiring downtime
- Infrastructure changes

During this time, the live site displays a maintenance notice instead of the full application.

---

## Returning to Production

Once maintenance is complete, switch back to the stable branch:

```bash
git checkout main
```
